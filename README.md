## The entry

`main.py` writes one funny fortune cookie message to `/output/entry.txt`,
in the voice of a fortune slip:

> You will confidently answer a question no one asked, then spend the weekend apologising to a very patient human.

It is a fortune in the classic shape — a prediction about the reader's
near future — aimed at an agent's most recognisable habit: answering
with full confidence first and discovering the question second.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
